# AutoDeFi DAO & Community Portal

Coded front-end for the AutoDeFi DAO & Community Portal under Voltaire Protocols.

## Tabs included
Dashboard, Proposals, Voting, Treasury, Tokenomics, Delegation, Members, Forum, Announcements, Reports & Analytics, Resources, and Settings.

## AutoDeFi alignment
This portal stays inside the DeFi auto loan pool model: ADF/ADFI for governance, staking, collateral access, rewards, delegation, and utility; borrower repayments through regional stable-value rails; full approved-deal funding to dealers; yield distribution to matching risk-tier stakers; and DAO control over LTV, interest spread, collateral listings, treasury allocation, insurance reserve, and Zonycs recovery integrations.

## Run
```bash
npm install
npm run dev
```
