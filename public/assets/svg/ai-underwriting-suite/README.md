## Usage

These SVGs are design-lock artifacts for the dashboard shell, layout, nav order, color semantics, component names, and tab-specific content direction.

They are not raster screenshots. They are intentionally editable, front-end handoff friendly, and ready to be converted into React SVG components or used as prototype assets.
