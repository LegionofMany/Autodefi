# AutoDeFi V1 Visual System

AutoDeFi V1 follows the rendered dark institutional dashboard direction.

## Visual Rules

- Dark cyber-finance terminal
- Left command sidebar
- Glass cards
- Neon blue, green, and purple highlights
- LP pool panels
- Dealer funding command center
- AI risk terminal
- ADF utility console
- Stable treasury module
- Hedera execution widgets

## Core Colors

- Background: #020617
- Blue: #00b7ff
- Cyan: #00e5ff
- Green: #00ff9d
- Purple: #8b5cf6
- Orange: #ff8a00
- Danger: #ff3b6b

## UX Rule

The UI must feel like one standalone institutional portal, not disconnected pages.
