# AutoDeFi V1 Flow Runner

The V1 flow runner proves the full AutoDeFi lifecycle.

## Command

pnpm run:v1-flow

## What It Proves

- Demo data exists
- Dealer payout record is executed
- Borrower record is active
- Payment record is posted
- Tier yield event is posted
- ADF collateral is locked
- Dashboard snapshot is created

## Purpose

The flow runner is the local completion proof for the V1 scaffold before deeper hardening.
