# AutoDeFi Whitepaper PDF Style Guide

This file documents the design direction for the branded AutoDeFi / ADF Token Whitepaper V2 PDF.

## PDF direction

- Document: `AutoDeFi_ADF_Whitepaper_V2_Designed.pdf`
- Source whitepaper: `docs/WHITEPAPER.md`
- Visual system: dark fintech / Voltaire Protocols
- Network direction: Hedera Hashgraph
- Token: ADF
- Marketplace layer: ZONYCS
- Identity and verification layer: Reqrium

## Brand styling

| Element | Direction |
|---|---|
| Background | Deep black / navy grid |
| Primary accents | Neon cyan and neon green |
| Secondary accents | Purple, blue, gold, amber |
| Cover badge | ADF hexagon / shield-style mark |
| Page framing | Branded header, footer, page number, legal notice |
| Tables | Dark panels with neon cyan headers |
| Diagrams | Simple node-and-flow diagrams with neon outlines |
| Tone | Investor-facing, compliance-aware, protocol-focused |

## Compliance language

The PDF must continue to state that it is a working project document and not financial, legal, tax, investment, lending, securities, or yield advice.

## Notes

The designed PDF is intended for review, investor conversations, pitch support, and future public-facing refinement after legal and compliance review.
