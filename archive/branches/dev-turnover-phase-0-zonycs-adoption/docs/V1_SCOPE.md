# AutoDeFi V1 Scope

## V1 status

AutoDeFi V1 is scoped as a production-ready React + TypeScript + Vite front-end shell with locked SVG product graphics and seed data ready for backend wiring.

## Included V1 modules

- Dashboard overview
- DAO proposals and voting
- Treasury management
- ADF staking
- Lender pool sections 1 through 6
- Risk management
- Revenue sharing
- ADF token utility
- Governance
- Audit and security
- Analytics
- Borrower portal
- Dealer portal / Block Motors
- Capital yield portal
- Insurance and recovery
- Admin command center
- AI Underwriting and Risk Command Suite SVG locks

## Out of scope for V1

- Live borrower underwriting decisions
- Production custody or fund movement
- Final smart contract deployment
- Final KYC/AML provider wiring
- Final lender/bank/dealer API credentials
- Production legal/compliance approvals

## V1 handoff rule

V1 must stay SVG-first, dark-fintech aligned, and ready for backend endpoint connection through `VITE_AUTODEFI_API_BASE`.
