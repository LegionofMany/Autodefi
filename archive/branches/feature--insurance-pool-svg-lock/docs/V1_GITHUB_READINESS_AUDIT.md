# AutoDeFi V1 GitHub Readiness Audit

This document tracks when AutoDeFi V1 is ready for repository review.

## Required Before V1 Complete

- Repo structure verified
- Environment templates complete
- Prisma schema validates
- Seed defaults work
- V1 demo seed works
- V1 flow runner passes
- API contract tests pass
- Frontend pages smoke test passes
- Design system check passes
- Security check passes
- Deployment config exists
- README has complete commands
- Docs cover architecture, scope, deployment, security, and demo flow

## Completion Command

pnpm complete:v1

## Branch Recommendation

Use v1-scaffold for first import, develop for active hardening, and main for stable releases.
