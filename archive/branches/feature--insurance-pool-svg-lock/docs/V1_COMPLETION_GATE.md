# AutoDeFi V1 Completion Gate

V1 is complete only when this command passes:

pnpm complete:v1

## What It Checks

- Repo structure
- Root scripts
- Environment templates
- Documentation
- Operator runbook
- Service imports
- API gateway paths
- Prisma schema
- Demo scripts
- Frontend fallbacks
- Security checks
- Visual design system
- Page styling
- Monorepo build
- Service builds
- Demo idempotency
- End-to-end V1 flow
- API contracts
- Route verification
- Page verification

## External Checks After Local Pass

- GitHub CI passes
- Deployment smoke test passes
- Legal and compliance review before real lending activity
