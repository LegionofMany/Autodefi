# Stable-Value Rails

## Locked repayment direction

Borrower repayment should use regional stable-value rails rather than ADF as the default loan payment currency.

## Purpose

Stable-value rails are used to reduce payment volatility for borrowers, dealers, capital providers, and the protocol.

## Front-end implications

The UI should represent repayment as stable-value rails and keep ADF positioned as staking, collateral, access, rewards, and governance utility.

## Future integration notes

Production implementation should add provider-specific payment rail configuration, regional compliance, receipts, reconciliations, transaction status, and repayment history endpoints.
