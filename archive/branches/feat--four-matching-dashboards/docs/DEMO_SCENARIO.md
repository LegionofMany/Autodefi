# AutoDeFi V1 Demo Scenario

## Flow

The demo creates a Tier 2 pool, a demo dealer, a demo vehicle, a demo borrower, a funded deal record, a posted payment record, an ADF collateral record, a yield distribution record, a reconciliation run, and a dashboard snapshot.

## Demo Details

- Vehicle: 2022 Tesla Model 3
- Dealer: ZONYCS Demo Motors
- Risk Tier: Tier 2 Standard
- Approved Amount: 32,000 USDC
- Term: 60 months
- ADF Collateral: 5,000 ADF

## Purpose

The demo is a technical verification path for the V1 repository scaffold.
