# AutoDeFi DAO Treasury Management Center

Dark fintech Web3 treasury portal for the AutoDeFi decentralized auto loan pool ecosystem.

## Included tabs

Treasury Operations:
- Dashboard
- Treasury Assets
- Allocations
- Revenue Streams
- Reserves
- Expenditures
- Budgeting
- Reports
- Audit Logs

Treasury Actions:
- Transfer Funds
- Swap / Convert
- Stake Assets
- Approve Spending
- Treasury Proposals

Analytics:
- Performance
- Cash Flow
- Scenario Planning
- Stress Testing

Configuration:
- Policies & Rules
- Multi-Sig Wallets
- Integrations
- Settings

## AutoDeFi alignment

The interface follows the AutoDeFi loan pool model with lending reserves, insurance reserves, borrower repayment revenue, dealer funding support, ADF token utility, DAO proposals, multi-signature approval, and treasury audit visibility.

## Run locally

Open `index.html` in a browser, or run:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
