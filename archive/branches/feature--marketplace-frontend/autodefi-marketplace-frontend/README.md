# AutoDeFi Marketplace Front-End

This folder contains the coded front-end for the AutoDeFi marketplace designs created in the chat.

## Included screens

- Marketplace grid page
- AutoDeFi Premium Access product page
- Insurance Booster Pack product page
- DeFi Analytics Pro product page
- AI Underwriting Pro Pack product page
- Dealer Pro Pack product page
- Staking Booster Tier 1 product page
- AutoDeFi Genesis NFT product page
- Vehicle NFT and merchandise marketplace cards
- Sidebar navigation, top navigation, purchase panels, right stats rail, category filters, security panels, trust footer, and news card

## AutoDeFi alignment

The UI follows the AutoDeFi / Voltaire Protocols dark fintech Web3 design language:

- Black/navy background
- Neon blue, cyan, purple, and green accents
- ADF token pricing
- Borrower, investor, DAO, insurance, staking, dealer, and marketplace ecosystem navigation
- Product cards for marketplace utility, boosts, analytics, underwriting, dealer tools, Genesis NFTs, vehicle NFTs, and merchandise

## Install

```bash
npm install
npm run dev
```

Open the local Vite URL in your browser.

## Build

```bash
npm run build
```

The production build will be generated in `dist/`.

## Notes

This is a front-end prototype. Cart actions, wallet connection, token balances, ADF payments, NFT minting, smart-contract calls, authentication, and live API data are mocked in the interface and ready for later integration.
