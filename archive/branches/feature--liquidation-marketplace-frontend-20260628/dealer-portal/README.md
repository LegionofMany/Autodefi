# AutoDeFi Dealer Portal Front End

This folder contains the coded AutoDeFi Dealer Portal front end built from the approved dark Web3 / DeFi auto loan pool layout.

## Included Dealer Tabs

- Dashboard
- Inventory
- Leads
- Deals
- Financing
- Customers
- Referrals
- Auctions
- Reports
- F&I Products
- Marketing Tools
- Settings

## AutoDeFi Alignment

The front end reflects the rules already locked into the AutoDeFi build:

- Approved dealer deals are funded to the dealer.
- Borrowers repay through regional stable-value rails.
- Interest yield routes to users staked in the matching risk-tier pool.
- ADF is used for staking, collateral, access, rewards, governance, and ecosystem utility.
- ADF is not treated as the default borrower payment currency.
- ZONYCS supports raffle, auction, and sale paths.
