# AutoDeFi Collections & Recovery Center

React/Vite front-end for the AutoDeFi loan pool Collections & Recovery portal.

## Screens included

- Dashboard
- Collections
- Delinquent Loans
- Recovery Pipeline
- Repossession Queue
- Recovery Assets
- Workouts
- Payment Plans
- Reports
- Analytics

## AutoDeFi alignment

This front end follows the AutoDeFi loan-pool model:

- Approved dealer deals are funded in full.
- Borrowers repay through regional stable-value rails.
- Yield from repayments flows to matching risk-tier capital pools.
- ADF is used for staking, collateral, access, rewards, governance, and ecosystem utility.
- ZONYCS is represented as the collateral recovery and liquidation channel.

## Run

```bash
npm install
npm run dev
```
